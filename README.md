# Milestone 3 — Consultations and prescriptions

This increment adds clinical follow-up to the scheduling workflow:

- record diagnosis, observations, and prescription against an appointment;
- mark that appointment as completed;
- list a patient's consultation history.

Milestone 3 builds on the data model introduced in `milestone-2`. The implementation fragment below is intentionally isolated so it can be reviewed as the third increment before the complete integrated app in `milestone-4`.
